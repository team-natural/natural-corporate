## 1. 事業概要（エレベーターピッチ）

対象は株式会社ナチュラルの事業そのもの。naturaling.jp はその入口（リード獲得の導線）にあたる。

- **誰のどんな課題を解決するか**: 企業の「AI・DX を進めたいが何から始めればよいか分からない」という状態と、業務システム・Web サイトを内製できないという状態を解決する。（出典: `/ai-dx/`・`/seminar/` のコピー、お知らせ `ai-dx-support-launch`）
- **提供する主要価値**: 課題の可視化から実装・運用定着までを、自社エンジニアの開発力でワンストップに提供する。診断・提案で終わらない点を明示している。（出典: `/ai-dx/`）
- **競合代替手段との差分**: 「"作れる会社"だからこそ話せる」— コンサルティング専業との差分を開発力に置いている。加えて国内チームとインドネシア・カンボジアの開発チームによる国際体制で、品質とコストを両立する。（出典: `/seminar/`・`/development/`）
- **収益化方法**: 3 事業カテゴリ。①システム開発（受託）②AI・DX 支援 ③自社サービス。加えてセミナーを入口として持つ。（出典: `/` トップの事業紹介）
- **今なぜやるのか**: **要記入**（00_INTAKE に入力なし）

**ミッション / ビジョン / バリュー**（出典: `/about/`）

| | |
| --- | --- |
| Mission | あらゆる境界をこえる |
| Vision | 世界をつなげる国際系 SIer。杜の都・仙台を拠点に、言語・文化に関係なく世界で活躍できる人材を育成し、グローバル社会の繁栄に貢献する |
| Value | ①多文化的なチームの力で課題に挑戦する ②技術の変化に対応できるよう自己研鑽し生産性を高める ③顧客のニーズを理解し、使いやすく魅力的なシステム開発を目指す |

| 区分 | 内容 | 影響範囲 | 対応方針 |

## 9. 記入時チェックポイント

- 誰の、どの課題を、どの場面で解決するかが明確か
- 価値仮説と価格仮説、要件仮説に矛盾がないか
- 除外スコープや前提条件が後続文書に引き継げる形で書かれているか
- ペルソナが具体的で、PRD-03 のユーザーストーリーに繋がるか
- フェーズ命名が「MVP 期 / 成長期 / 安定期」で統一され、移行条件が BIZ-02 §3 と二重管理になっていないか
- コンテンツ主体（パターン A）の前提から外れていないか（マルチテナント SaaS・複雑な業務ロジックが事業の中心になっていないか）
