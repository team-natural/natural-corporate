# 02-open-questions.md — 未決事項管理テンプレート

## このセクションの目的

未決事項、保留論点、追加調査が必要な論点を一元管理する。**全フェーズ横断・プロジェクト開始初日から運用する**。解決した時点で GOV-01 へ転記。

## 0-H. ハイブリッド編集ガイド（要点）

- 推奨モード: Human-first または Hybrid
- 人間確認必須: 本当に未決か、期限妥当性、解決に必要な意思決定者

### 2-4. AI 機能

AI 機能（PRD-05）は**現時点で未採用**。サイト上の「AI・DX 支援」は提供サービスの名称であり、サイト自体に LLM 連携は実装していない。**診断プラットフォームの有料版（BIZ-04 Phase 3）で「AI 分析」として採用する候補**が PRD-05 に起案されており、採否・プロバイダは §2-6 の TBD-28 で扱う。採用時は DEV-01 §2 の標準ライブラリに従い、GOV-01 に決定を記録する。
